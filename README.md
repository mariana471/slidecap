# SlideCap — 학회 발표 슬라이드 자동 캡처 (갤럭시 · 아이패드)

카메라를 켜 두기만 하면 스크린을 자동으로 찾아, 슬라이드가 바뀔 때마다 정면 보정된 이미지로 저장합니다.
셔터를 누를 필요가 없고, 옆자리에서 비스듬히 찍어도 정면에서 찍은 것처럼 펴집니다.
설치 앱이 아니라 **브라우저에서 도는 웹앱(PWA)** 이라서 갤럭시(Chrome)와 아이패드(Safari) 모두에서 동작합니다.

## 파일 (전부 올리세요)
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (감지·보정·저장·OCR·녹음·자막) |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | 홈 화면에 앱처럼 설치하기 위한 메타데이터와 아이콘 |
| `sw.js` | 오프라인 캐시(한 번 열어 두면 인터넷 없이도 앱이 열림) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하게 하는 빈 파일 |
| `README.md` | 이 설명 |

## 1. 올리기 (한 번만, 5분)
카메라·마이크는 **HTTPS 주소**에서만 열리므로 파일을 어딘가에 올려야 합니다.

**GitHub Pages (무료, 영구) — 권장**
1. github.com 에서 새 저장소 생성(Public, 이름 예: `slidecap`).
2. "Add file → Upload files" 로 위 파일을 모두 올리고 Commit. (`.nojekyll`처럼 점으로 시작하는 파일은 숨김 파일이라 안 보일 수 있으니 폴더를 통째로 끌어다 놓으세요.)
3. Settings → Pages → Branch를 `main` / `(root)` 로 선택 → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/slidecap/` 가 열립니다.
5. 나중에 파일을 고쳐 올리면 폰에는 최대 10분 뒤에 반영됩니다(GitHub 캐시). 바로 보려면 폰에서 새로고침을 두 번 하세요.

**Netlify Drop (가입 없이 즉시, 임시 테스트용)**
https://app.netlify.com/drop 에 PC에서 `slidecap` 폴더를 끌어다 놓으면 바로 주소가 나옵니다. 단, 로그인해서 사이트를 "claim" 하지 않으면 잠시 뒤 사라지므로 학회용으로는 GitHub Pages를 쓰세요.

## 2. 폰/패드에서 설치
- 갤럭시: Chrome으로 주소 열기 → ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가".
- 아이패드: Safari로 열기 → 공유 버튼 → "홈 화면에 추가". 카메라 권한은 홈 화면 앱을 열 때마다 다시 물어보니 "허용"을 누르세요.
- 아이패드 주의: 홈 화면 앱에서는 **실시간 자막(음성 인식)이 동작하지 않습니다**. 자막이 필요하면 Safari 탭에서 쓰세요. 녹음·캡처는 둘 다 됩니다.

## 3. 학회장에서 쓰는 법
1. 가로로 들고(가능하면 받침/삼각대) 스크린 전체가 화면에 들어오게 둡니다. 화면 꺼짐 방지를 앱이 요청하지만 아이패드(특히 iPadOS 17 이하)에서는 안 될 수 있으니 **설정 > 디스플레이 > 자동 잠금을 "안 함"** 으로 두세요.
2. **카메라 시작** → 초록 사각형이 스크린을 따라가면 준비 끝. 3초 안에 못 찾으면 주황색 고정 영역이 생기니 모서리를 손가락으로 끌어 맞추세요(어두운 테마 슬라이드, 밝은 방의 TV 등).
3. 멀리서 찍어 화면이 작으면 카메라 아래 **줌** 슬라이더를 올리세요(지원 기기에서만 표시). **노출** 슬라이더는 스크린이 하얗게 날아갈 때 내립니다.
4. 발표 화면이 바뀌고 약 1초 안정되면 자동으로 저장됩니다(찰칵 효과 + 우상단 미리보기). 글머리 기호가 하나씩 나타나는 애니메이션은 마지막 상태로 갱신되고, 발표자가 앞을 가리면 가려진 장면은 건너뛰거나 나중에 깨끗한 장면으로 바뀝니다.
5. 발표 음성은 **⏺ 녹음** 버튼을 누르세요. 소리 없이 녹음되고 슬라이드마다 녹음 시각이 기록됩니다(10초마다 저장되어 앱이 꺼져도 남음). 실시간 자막은 선택 기능입니다(아래 참고).
6. 끝나면 **ZIP 만들기** → 버튼이 "ZIP 저장/공유"로 바뀌면 한 번 더 누릅니다. 갤럭시는 다운로드 폴더에 저장되고, 아이패드는 공유 시트가 떠서 파일 앱에 저장할 수 있습니다. **사진 앱으로 공유**는 이미지만 사진 앱에 넣습니다(갤럭시는 10장씩, 버튼을 반복해서 누름).

ZIP 내용: `slides/slide_001.jpg …`(정면 보정 이미지), `slides.txt`(슬라이드별 OCR 텍스트), `audio/rec_01_….webm|m4a`(녹음), `timeline.txt`(슬라이드별 시각·녹음 위치), `transcript.txt`(실시간 자막), `notes.md`(전부 슬라이드별로 합친 노트).

녹음 파일은 나중에 Clova Note, 갤럭시 음성 녹음 앱의 텍스트 변환, 또는 Claude에 올려서 글로 바꿀 수 있고, `timeline.txt`의 시각으로 어느 슬라이드에서 한 말인지 찾을 수 있습니다.

## 실시간 자막(음성 인식)을 쓸 때
- 인터넷이 필요합니다(Google/Apple 서버에서 인식).
- 갤럭시 Chrome은 인식이 재시작될 때마다 **알림음**을 냅니다. 쓰려면 폰을 무음 + 미디어 볼륨 0으로 두세요. 조용한 학회장에서는 녹음을 권합니다.
- 아이패드는 Safari 탭에서만 되고, 설정 > 일반 > 키보드 > "받아쓰기 사용"이 켜져 있어야 합니다. 몇 초씩 빠질 수 있습니다.

## 설정 설명
- **변화 민감도**: 낮을수록 작은 변화에도 새 슬라이드로 저장. 기본 11(화면의 약 4% 이상이 바뀌면 저장). 너무 자주 저장되면 올리세요.
- **안정 대기**: 화면이 몇 프레임(≈0.33초/프레임) 멈춰야 저장할지. 손 흔들림·전환 애니메이션 중 저장을 막습니다.
- **돌아가면 건너뛰기**: 발표자가 이전 슬라이드로 돌아갔을 때 중복 저장을 막습니다.
- **슬라이드 비율**: 보통 16:9. 구형 자료는 4:3. "자동 추정"은 카메라 각도를 계산해 비율을 추정합니다(정확하지만 흔들리면 조금 변함).
- **파일로 처리**: 미리 녹화한 영상(2배속으로 훑음)이나 비스듬히 찍은 사진 여러 장을 넣어도 같은 방식으로 추출합니다. 아이패드에서 실시간 자막이 불안하면 영상으로 녹화해 두고 나중에 돌리는 방법도 있습니다. (iPadOS 17.4에서는 영상 파일 처리가 안 되는 버그가 있으니 17.5 이상으로 업데이트하세요.)

## 저장과 오프라인
- 슬라이드·녹음·자막은 그 기기의 브라우저 저장소(IndexedDB)에 남습니다. 발표가 끝나면 ZIP으로 꼭 내려받으세요.
- 아이패드 Safari 탭은 7일 동안 사이트를 안 열면 저장 데이터가 지워질 수 있습니다(홈 화면 앱은 예외). 홈 화면 앱과 Safari 탭은 저장소가 서로 다릅니다.
- 한 번 인터넷에서 열어 두면 카메라 캡처·녹음은 오프라인에서도 됩니다. ZIP 만들기와 OCR도 한 번 써 두면 캐시되지만, 첫 사용은 인터넷이 필요합니다(OCR 언어 데이터 약 9MB). 실시간 자막은 항상 인터넷이 필요합니다.

## 동작 원리(짧게)
밝기 기준(오츠 임계값을 실내 배경 밝기에 맞춰 보정)으로 스크린 영역을 찾고, 가장 큰 연결 영역의 네 꼭짓점을 잡아 호모그래피로 정면 변환합니다. 밝은 벽에 걸린 TV의 어두운 제목 띠는 비율을 보고 위아래로 확장해 되찾습니다.
변환된 96×54 축소 이미지를 8×9 블록으로 나눠 매 프레임 비교하고(노출 변화·노이즈·1픽셀 흔들림에 둔감), "안정 + 새로움" 두 조건이 맞을 때만 고해상도(기본 1600px)로 저장합니다. 변화 방향으로 '내용 추가(빌드)', '뒤로 가기', '사람이 가림', '가림 해제'를 구분해 갱신·무시·저장을 결정합니다.
OCR은 Tesseract.js(기기 내 처리), 녹음은 MediaRecorder, 자막은 브라우저 내장 음성 인식(Web Speech API)을 씁니다.

## 알아둘 한계
- 검은 배경 슬라이드만 계속되는 발표는 밝기 기준으로 스크린을 찾기 어렵습니다. 밝은 슬라이드일 때 잡힌 영역을 **영역 고정**으로 잠가 두거나 모서리를 직접 맞추세요(카메라를 움직이지 않는 한 그대로 맞습니다).
- 브라우저가 백그라운드로 가면(다른 앱 전환, 화면 꺼짐) 캡처가 멈춥니다. 돌아오면 카메라를 자동으로 다시 연결합니다.
- 슬라이드 안에서 영상이 재생되면 6초 간격으로 여러 장이 저장될 수 있습니다. 끝나고 지우세요.
- 저장 순간 약 0.2~0.4초 화면이 멈추는 것은 정상입니다(고해상도 보정 중).
